Sample RAR files for `ArchiveTest`, from the [junrar](https://github.com/junrar/junrar) project's test data
(`rar4.rar`: two 7-byte text files, FILE1.TXT and FILE2.TXT; `rar5-solid.rar`: a RAR5 archive, which FilesCtrl
reports as unsupported). FilesCtrl can't create RAR files itself, so real ones are needed to test reading them.
